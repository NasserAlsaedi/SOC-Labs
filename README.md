# SOC Labs Portfolio

## About

This repository contains SOC analyst home lab projects and security investigations.

## Tools Used

- Splunk
- Wireshark
- Sysmon
- Windows Event Viewer
- VirusTotal
- URLScan
- TryHackMe

## Investigations

### 1. RDP Brute Force Investigation

- Investigated Event ID 4624 and 4625
- Identified successful login after multiple failed attempts
- Analyzed source IP activity

### 2. Suspicious PowerShell Investigation

- Investigated PowerShell execution activity
- Reviewed parent process and command line
- Analyzed suspicious behavior

### 3. New User Creation Investigation

- Investigated Event ID 4720
- Verified account creation activity

### 4. User Added to Administrators Group Investigation

- Investigated Event ID 4732
- Reviewed privilege escalation activity

### 5. Phishing Email Investigation

- Investigated phishing email alerts
- Analyzed malicious URLs
- Reviewed phishing indicators
